## 更新约定

- 未完成使用 `- [ ]`；完成后改为 `- [x] ✅`，并在文末的完成记录中注明日期、条目编号、实现范围和实际验证结果。
- 每次补齐解析功能，必须在同一次变更中更新本文件。部分完成时拆分条目，保留未完成部分，不能直接勾选整个类别。
- 新发现的缺口追加到对应类别。条目编号保持稳定，方便关联任务和完成记录。
- 勾选表示条目所述范围已实现，不代表所有相关标准用例均通过。未编译、未执行测试或未验证回写时必须如实注明；仍遵循用户对构建和测试命令的限制。
- 解析补全涉及预览编辑时，同时检查 HTML 回写、源码位置同步和已有 Mermaid 行为，记录尚未验证的部分。
- 实际开发任务仍通过 `scripts/task.sh` 登记；本文件只维护功能覆盖进度，不替代 `tasks/TASKS.md`。

## 已完成的局部补全

- [x] ✅ MD-001 常见嵌套列表：保留缩进，支持父子分组、多级回退、有序/无序混用和 Tab 缩进。完整列表规则仍见 MD-105～MD-108。
- [x] ✅ MD-002 分隔线写法：支持三个及以上同类 `*`、`-`、`_`，允许标记间空格或 Tab、行首最多三个空格；连续分隔线保持独立节点和源码锚点。Setext 优先级仍见 MD-101。

## CommonMark 基础解析待办

### 标题与容器结构

- [ ] MD-101 支持 Setext 标题（文字下方的 `===`、`---`），正确处理标题与分隔线的优先级。
- [ ] MD-102 正确处理 ATX 标题的可选尾部标记，例如 `## 标题 ##`，并补齐空白和缩进边界。
- [ ] MD-103 支持嵌套引用，以及引用内的标题、列表、代码块等块级内容。
- [ ] MD-104 补齐引用续行及省略 `>` 的合法段落续行规则。
- [ ] MD-105 支持 `1)` 有序列表标记，保留非 1 的起始编号。
- [ ] MD-106 支持列表条目内的续行、多段文字及空条目。
- [ ] MD-107 支持列表条目内的标题、代码块、引用和分隔线。
- [ ] MD-108 补齐列表标记宽度、内容缩进、松紧列表、标记切换和段落中断规则，不能仅凭缩进增加判定子列表。

### 代码、强调与文本

- [ ] MD-109 支持波浪号代码围栏，正确匹配围栏字符、长度、合法缩进和关闭条件。
- [ ] MD-110 支持缩进代码块，并正确区分段落续行与容器缩进。
- [ ] MD-111 支持多反引号行内代码，正确处理内部反引号、换行及空白规范化。
- [ ] MD-112 补齐加粗与斜体的嵌套、标记边界和优先级，避免普通文本中的下划线被误解析。
- [ ] MD-113 支持反斜杠转义，让转义后的 Markdown 标记按文字显示。
- [ ] MD-114 支持行尾两个空格或反斜杠产生的强制换行，并区分软换行。
- [ ] MD-115 支持命名实体和数字字符引用，避免把 `&amp;` 等内容重复转义。

### 链接、图片与 HTML

- [ ] MD-116 支持链接与图片的引用式写法及引用定义解析。
- [ ] MD-117 补齐内联链接与图片的标题属性、地址括号配对、转义和合法空白规则。
- [ ] MD-118 支持尖括号自动链接，包括网址和电子邮件地址。
- [ ] MD-119 明确原始 HTML 的支持与过滤策略，并据此处理 HTML 块和行内 HTML；当前按文字转义，不作为已兼容项。

## GFM 扩展待办

- [ ] MD-201 表格列对齐：让分隔行中的冒号实际控制列对齐。
- [ ] MD-202 表格单元格解析：正确处理转义的竖线，包括行内代码中的合法写法。
- [ ] MD-203 表格结构：校验表头与分隔行列数，按规则处理数据行列数和表格终止边界。
- [ ] MD-204 任务列表：将 `- [ ]`、`- [x]`、`- [X]` 解析为复选框；预览编辑时保留完成状态。
- [ ] MD-205 扩展自动链接：识别符合 GFM 规则的裸网址和邮件地址。
- [ ] MD-206 删除线：在已有简单 `~~文字~~` 支持上补齐 GFM 的标记数量、边界和组合规则。
- [ ] MD-207 若启用原始 HTML，同步明确并实现 GFM 的不允许标签过滤规则。
