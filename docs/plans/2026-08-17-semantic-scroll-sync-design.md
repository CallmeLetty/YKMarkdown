# Markdown 原文与预览语义滚动同步设计

## 目标

在分栏模式下，让 Markdown 原文编辑区与可编辑预览区双向联动滚动。同步不得使用全文或章节滚动百分比，避免图片、代码块、表格和字体差异造成累计错位；现有目录高亮与目录点击跳转保持不变。

## 方案

渲染器为每个顶层 Markdown 内容块写入 `data-source-offset`。这个值是该内容块在规范化 Markdown 字符串中的 UTF-16 起始位置，与 `NSTextView` 使用的字符索引一致。锚点覆盖标题、段落、列表、代码块、引用、表格和分隔线。

原文编辑区滚动时，取视口顶部对应的字符索引并选择不晚于该位置的最近内容块锚点，将锚点源位置发送给预览。预览区直接滚动到带有同一源位置的 DOM 节点。预览滚动时反向选择位于视口顶部的最近 DOM 锚点，把它的源位置发送给原文编辑区，原文侧再把对应字符位置放到视口顶部。整个过程只使用离散内容锚点，不计算滚动比例。

两侧分别维护带 UUID 的滚动请求，并记录最近已处理的请求。程序触发目标侧滚动时临时抑制该侧的滚动上报，防止两边互相触发形成回环。连续用户滚动只在顶部所对应的内容锚点发生变化时发送新请求，减少无意义刷新。

预览区直接编辑导致 Markdown 变化时，不替换当前 DOM，以保留光标和焦点；只根据最新 Markdown 重新生成顶层源位置列表并更新现有预览块的锚点属性。

## 验证

- 渲染结果包含稳定的 UTF-16 源位置锚点。
- 生成的预览脚本包含锚点上报、锚点更新和按源位置滚动接口。
- macOS 工程编译成功。
- 手动检查长段落、图片、代码块、列表和表格附近的双向滚动，确认没有滚动回环，目录行为不变。
