# 排版主题与自定义背景设计

YKMarkdown 新增三种排版主题：温润写作、现代极简和程序员编辑器。主题是独立于现有“强调色”的第二条外观轴：强调色继续控制工具栏 tint、目录选中态和链接，排版主题负责编辑区与预览区的字体、行距、内容宽度、留白、代码块及基础明暗关系。选择结果使用 `AppStorage` 持久化，并在当前所有文档窗口中实时生效。

自定义背景色作为单独开关存在。关闭时，每个主题使用自己的默认稿纸色；开启时，同一个颜色同时应用到原生 Markdown 编辑区和 WebKit 预览区。系统根据背景色的相对亮度选择深色或浅色前景色，并从背景与前景混合生成次级文字、边框和代码块颜色，避免用户选择深色背景后出现不可读文字。关闭自定义背景不会丢弃已选择的颜色，再次开启时恢复上次值。

原生编辑区由 `AppTypographyTheme` 提供字体、行距和内边距，由解析后的背景/前景色设置 `NSScrollView` 与 `NSTextView`。预览区把主题标识、背景色、前景色和明暗模式传给 HTML renderer；运行中通过 JavaScript 只更新 CSS 变量及 `data-typography-theme`，不重新载入页面，因此保留滚动位置、选区和编辑焦点。Mermaid 在外观切换后重新渲染，以匹配新明暗模式。

设置页在“外观”区先展示排版主题和说明，再展示自定义背景开关与颜色选择器，最后保留现有强调色设置。验证覆盖无效存储值回退、默认主题背景、亮暗背景的前景色选择、生成 HTML 的主题变量与实时更新接口；完成后执行严格 macOS 编译和必要的界面检查，不运行 SwiftLint。
