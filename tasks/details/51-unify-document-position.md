# 51-unify-document-position

- Number: 51
- Slug: unify-document-position

## 实现

- EditorView 使用源码偏移统一路由位置，目录标题由该位置派生；移除独立标题跳转和两侧分别更新目录的通道。
- 源码上报滚动、光标及选区变化，同轮事件优先采用选区位置；SwiftUI 刷新和被动定位不回传。
- 预览统一上报点击、选区、滚动及页内链接位置，按帧合并事件；被动定位取消待发送事件，连续请求仅由最后一次解除抑制，真实用户输入可立即接管。
- 所有搜索跳转共用位置路由；源码保留精确匹配选区，目录和预览跟随。布局切换恢复当前位置，不取消搜索选区定位。
- 跟随不改变键盘焦点或被动区域的选区。预览使用已有源码块映射，定位粒度为段落、标题、代码块等，不是字符级映射。
