# 写作与工具的距离

好的写作工具不该抢走注意力。它应该退到纸张背后，只在你需要的时候出现。

## 字体不是装饰

一套排版首先要解决的不是“漂亮”，而是阅读节奏。中文、English 与 `inline code` 混排时，字面大小、基线和留白必须彼此协调。

> 当界面安静下来，内容才会发出声音。

我希望编辑器保留清晰的 Markdown 结构，同时让右侧预览接近文章最终发布时的状态：

- 正文有稳定、舒展的行距
- 标题足够明确，但不压迫正文
- 代码与引用可以被一眼识别

```swift
let idea = Draft(title: "新的文章")
editor.focus(on: idea)
```

最后一点克制

设计并不是不断添加，而是在每一个选择中找到恰当的分寸。更长的正文会被限制在舒适的阅读宽度内，不会随着窗口一起无限拉长。
